# Agents are Widgets; the core ships with none

The core defines one Agent interface: start a Session (role, prompt, worktree, permissions), receive its events (progress, asks, finished), and stop it. It contains no Agent of its own. Claude Code and OpenCode are both first-party Widgets in the public widget repo, and both are built in v1. The reason is practical: some workplaces don't allow Claude Code and use OpenCode instead. The old board built Claude Code's hooks, permission prompts and session IDs into its core. Shipping two adapters from the start means any Claude-only or OpenCode-only assumption shows up as a broken interface early. One consequence: Kiln needs its own abstract permission asks, which each Agent Widget translates into its tool's own permission model.
