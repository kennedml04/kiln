# The core and first-party Widgets share one public repo; private Widgets live in separate local repos

The public repo holds the core and the first-party Widgets together, so they share one version history and the Widgets are tested against the core in the same CI. Private Widgets (personal hobbies, anything not meant to be shared) live in separate Widget sources: local folders or private git repos that are never pushed to a public remote. This carries forward the old repo's ADR 0002 ("this repo stays local") for the private side only. Every install is pinned to an exact tag or commit in a lockfile. On corporate machines, the Org Policy can restrict which Widget sources are allowed. This replaces the old layout, where the board and personal hobbies all shared one tree and one git history, so the board couldn't be published or installed elsewhere.
